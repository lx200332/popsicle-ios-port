## 一、结论

1. **`audio`/`camera`/`fp` 三个驱动的门禁在 cmdline 里全是开着的（`audio_probe=1 camera_probe=1 fp_probe=1`），但 klogY 那一次启动用的内核里根本没有调用它们**——`_sweet_ufs_init` 的 bl 列表在 `pandora_usb_init` 之后直接跳到 `fuxi_keys_init`；klogY（00:41）早于第一个含全套调用的 out40（00:48），这份日志不能作为当前内核的证据。
2. **`pandora_sensors` 与 `pandora_amp` 则是真正的「门禁没开」**：两个名字都不在 605 B cmdline 里，`pandora_sensors_init` 走 L75-77 静默 return、`pandora_amp_init` 走 L1762-1764 静默 return；其中 `pandora_amp_init` 在旧内核里确实被调用了，所以 amp 是「调用到了但门禁关」的干净样本。
3. **依赖层面全部不成立**：树里 0 个 I2C/SPI/GENI 控制器驱动，DTS 里 28 个 `i2c@` 只有 8 个有子设备、21 个 `spi@` 只有 4 个有子设备且指纹 SPI 缺席，传感器零节点、SSC 在 ADSP+userspace；即使门禁和调用都补齐，这四个驱动也只能打到「打印巡检值」为止，真实总线事务一个都发不出去。

### A 类：加日志诊断（0 依赖、0 风险，立刻可分「没调用」vs「门禁关」）

| A1 | `sweet_ufs.c:1603-1617` 每个 init 前 | `printf("PANDORA INIT: →%s\n", "popsicle_audio_init")` 之类，共 15 行。这一步能一次性消灭「到底是没调用还是门禁关」的全部猜测 |

## 六、做不到的项

| 项 | 为什么做不到 | 结论强度 |
|---|---|---|
| **传感器 6 类（accel / gyro / mag / light / prox / baro）在 XNU 内核内驱动** | ① DTS 零节点（15 个 vendor 前缀全 0 命中）；② 树内零 I2C 控制器驱动；③ 真机传感器由 **SSC** 承载，SSC = ADSP 固件（`libsns_*_skel.so`）+ **userspace**（`sscrpcd`、`sensors-service.multihal`、`hals.conf` 5 个 so）；④ XNU 侧零 `sns_` 客户端。要在内核里做到，等于把 Android sensors HAL 的整套 GPR 协议搬进内核 | **永远做不到**（除非改写整个 sensors 栈的归属） |
| **指纹 sensor 出数据** | ① 无 SPI 子节点；② 无 GENI SPI 控制器驱动；③ 即使补上，goodix/OV 系指纹的协议与固件下发流程仓库里零证据。当前唯一能做的就是把 GPIO99 / GPIO56 的寄存器值读出来打印 —— 那正是现在干的事 | **做不到**（只能停在巡检） |
| **相机真实成像** | ① CCI 寄存器映射缺失（`cam_cci_read_reg` 只 `return KERN_NOT_SUPPORTED`）；② 4 个 sensor 的 chip-id 偏移全缺；③ s1/s2 根本不在 CCI 上而在 AP GENI I2C（无驱动）；④ **树内零 CAMSS/ISP 驱动** —— 没有 ISP 就没有 YUV 出图路径 | **做不到**（最佳情况是读到 s0/s3 的 chip-id） |
| **音频出声** | ① ADSP 从未 ready（`firmware pack: 3 files` 只有 3 个 GPU 文件；日志 L1929-1932 逐条打 `adsp_dtb.mdt missing in the pack` → `DTB image failed 2` → `adsp.mdt missing in the pack` → `main image failed 2`，PAS 把 adsp(1)/adsp_dtb(36) 直接 shutdown）；② 无 GENI I2C master → WCD9395 codec 一个字节都写不进去；③ TDM0 无 controller 节点、无 IRQ；④ 无 LPASS DMA 通道；⑤ 无 AudioReach APM 共享内存区。代码自己写死 ENOTSUP（L338-341 / L348-351） | **做不到**（写路径最多做到 pinmux 改电平 + WCD9395 reset 脉冲） |

| **`pandora_sensors` 升级成驱动** | 它自己就是「证据打印器」，注释 L42-53 明写「Until (a) is decided, any code below this comment would be invention」 | **设计上就不该做** |
